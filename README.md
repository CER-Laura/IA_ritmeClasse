#Documentació de la pàgina sobre la IA
Aquesta es una pàgina treballada a classe per aprendre HTML i CSS. Veurem les etiquetes més modernes d'HTML5 i després, aplicarem estils en un fitxer a part.

> [!NOTE]
> Aquest projecte només té finalitats educatives.

##Estructura de la pàgina
La pàgina està composta per les següents seccions:
- **Introducció**: Presentació de la IA
- **ChatGPT**: Informació sobre ChatGPT
- **Gemini**: Informació sobre Gemini
- **Claude**: Informació sobre Claude

##Tecnologies utilitzades
- HTML5
- CSS3
- JavaScript
